# 워리어 실드 수정 v4

기본 방패 높이 440px, 펼친 방패 높이 1320px. 캐릭터 기준 높이 440px로 1:1 → 1:3입니다. 캐릭터가 방패 중앙 높이에서 잡고, 방패가 위아래로 확대됩니다. 확대는 이미지에 반영되어 있으므로 캐릭터 Transform Scale을 키우지 않습니다.

## 구성
- Frames/Shield/Idle: 6장, 반복
- Frames/Shield/Move: 6장, 반복
- Frames/Shield/Deploy: 12장, 1회 재생 후 Guard
- Frames/Shield/Guard: 6장, 반복
- Effects/Shield/DeployFX: 12장, Deploy와 같은 프레임 번호로 전개 순간 재생
- Effects/Shield/GuardFX: 6장, 방패를 유지할 때 반복
- Effects/Shield/BlockHitFX: 6장, 실제 방어 성공 순간 별도로 재생
- Parts: 기본/전개 방패 단독 PNG 2장. 합쳐진 캐릭터 Frames를 쓰면 추가로 겹쳐 넣지 않습니다.

애니메이션용 54장 + 방패 부품 2장 = 투명 PNG 56장입니다. 전개 시간을 N초로 정하면 12개 프레임을 N/12초 간격으로 배치합니다. 역순으로 쓰면 접히는 동작이 됩니다.

## Unity 가져오기 기준
모든 PNG 3072×3072, Texture Type Sprite (2D and UI), Sprite Mode Single, PPU 100, Filter Mode Point, Compression None, Max Size 4096, Generate Mip Maps Off, Alpha Is Transparency On.

Pivot Custom: X 0.5 / Y 0.423828125. 캐릭터의 발 기준선은 이미지 위쪽 기준 y=2000입니다. Body와 Effects는 같은 캔버스와 피벗으로 정렬했습니다. 효과용 자식 오브젝트는 Local Position (0,0,0), Local Scale (1,1,1)로 두고 캐릭터보다 앞에 그리면 됩니다. 프레임 개별 자동 잘라내기나 서로 다른 PPU를 쓰면 정렬이 달라집니다.

Frames에는 이미 방패가 포함되어 있습니다. 전개/유지 효과와 피격 효과는 각각 별도의 렌더러에서 재생하는 구성입니다. 실제 막아낸 순간과 데미지 판정은 이번 파일에 포함되지 않습니다.

## 검증 범위
모든 PNG의 투명 알파, 캔버스 크기, 가장자리 잘림 여부를 검사했습니다. 기준 몸체 높이와 방패 높이/전개 중심을 픽셀 수치로 정렬했습니다. 새로 그린 자세이므로 기존 워리어와 모든 윤곽 픽셀이 동일한 파일은 아닙니다. 게임 실행 검증 및 프로젝트 적용은 하지 않았습니다.

Previews의 비교 이미지는 두 상태에 동일한 축척을 사용합니다. GIF 배경은 미리보기용이며 실제 PNG는 투명합니다. 기존 v3의 실드 폴더 대신 이 파일들을 사용하고 다른 무기 파일은 그대로 사용하면 됩니다.
