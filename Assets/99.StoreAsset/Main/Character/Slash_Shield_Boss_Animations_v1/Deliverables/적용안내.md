# Slash 장검 · 방패 2종 효과 · 보스 연출

현재 프리팹과 SpriteLibrary가 참조하는 원본을 읽고 제작했습니다. 프로젝트는 수정하지 않았습니다. 개별 RGBA PNG와 미리보기, Import 설정, 프레임별 시간표를 제공합니다. 본체는 원본 픽셀을 분리·회전·이동해서 연출했고, 새 폭발과 방패 충돌 원화는 이미지 생성 도구로 만들었습니다. 84장의 독립적인 재생성 원화가 아니라, 일관된 원본과 분리 부품으로 만든 84개의 시간 프레임입니다.

|---|---:|---|

| Slash_Longsword/Attack | 4 | 기존 Attack 시간에 연결 |

| Dog_Death_3p5s | 84 | 24 FPS, 3.5초, 반복 끔 |
| Head_Death_3p5s | 84 | 24 FPS, 3.5초, 반복 끔 |

네 개의 보스 연출 폴더에는 같은 시간표의 Combined, Body_Only, FX_Only가 각각 있습니다. **간단히 캐릭터 애니메이션에 연결하려면 Combined만 사용**하세요. 효과의 정렬·색상·재생을 따로 제어할 때만 Body_Only와 FX_Only를 함께 사용합니다. Combined 위에 FX_Only를 또 겹치면 효과가 중복됩니다. 프레임 끝의 완전 투명 이미지는 정상적인 소멸 상태입니다.

## 크기·피벗

| 종류 | PNG 캔버스 | PPU | Pivot |
|---|---|---:|---|
| Slash 장검 | 1536×1536 | 100 | Custom (0.5, **0.4622395833**) |
| 방패 펼침 | 3072×3072 | 100 | Custom (0.5, **0.423828125**) |
| 방패 방어 성공 | 512×512 | **1000** | Center (0.5, 0.5) |
| Dog 입 동작 | 149×94 | 100 | Center |
| Dog 사망 | 213×158 | 100 | Center |
| Head 사망 | 176×185 | 100 | Center |
| 크루저 사망·전환 | 448×320 | 100 | Center |

Texture Type은 Sprite (2D and UI), Sprite Mode는 Single, Filter Mode는 Point, Compression은 None, Alpha Is Transparency를 켭니다. Max Size는 원본 PNG가 축소되지 않도록 Slash 2048 이상, 방패 펼침 4096 이상, 나머지 512 이상으로 설정하세요. Parts 폴더는 제작 참고용 부품으로, 완성 캐릭터의 피벗을 그대로 적용하는 대상이 아닙니다.

기존 보스보다 **캔버스는 크지만 본체 픽셀은 확대하지 않았습니다.** Dog와 Head는 사방 56픽셀, 크루저는 사방 96픽셀의 투명 여백을 붙였습니다. Dog 입 동작은 사방 24픽셀입니다. 동일 PPU와 중앙 Pivot을 사용하면 원본 본체의 월드 크기와 중심이 유지됩니다. 여백에 맞춰 보스 Transform을 줄이면 안 됩니다.

Slash는 원본 1024 캔버스에 사방 256픽셀을 붙여 장검 끝이 잘리지 않게 했습니다. 기존 피벗의 원본 픽셀 위치를 새 캔버스에 옮긴 값이 위의 0.4622395833입니다. Warrior Renderer의 기존 0.2 스케일을 유지하세요. 원본의 손·몸·다리 자세를 사용하고 단검 부위를 제거하여 장검을 연결했습니다. 이번 Slash에는 Idle 4컷과 기존 1단 공격용 4컷을 제공하며, 별도 2·3단 추가 공격은 포함하지 않았습니다.

## 방패 효과 두 가지

**펼침 효과:** 이전 묶음의 전방 하늘색 파장을 Deploy_8frames라는 이름으로 다시 포함했습니다. 방패를 올리는 순간에만 재생하고, 누르고 있는 동안 계속 새로 생성하지 않습니다. 캐릭터 정렬용 캔버스이므로 본체 Renderer와 같은 위치·스케일·좌우 방향에서 사용합니다.

**방어 성공 효과:** 이번에 추가한 작고 강한 흰색·하늘색 충돌 불꽃입니다. 방패가 공격을 실제로 막은 위치에서 재생합니다. Guard 자세 진입, 일반 피격, 공격 버튼 입력과는 다른 발동 조건입니다.

현재 Shield.cs는 방어 성공 시 _hitEffectPrefab을 hitPoint에 생성합니다. 이 슬롯에 사용할 **방패 전용 이펙트 프리팹**을 별도로 준비하세요. 기존 공용 HitEffect 프리팹을 직접 바꾸면 다른 피격 연출도 바뀔 수 있습니다.

- SpriteOneShotEffect의 Frames: Shield_BlockHit_01~12 순서.
- Frames Per Second: 24.
- 프리팹 Transform Scale: (1, 1, 1), Sprite PPU: 1000.
- Start Scale Multiplier: 1, End Scale Multiplier: **1**.
- 확대·소멸이 PNG 프레임에 이미 들어 있으므로 기존 기본값 End=2를 사용하면 이중으로 커집니다.
- 위 설정의 최대 효과 높이는 약 0.41 월드 단위입니다. 현재 워리어 본체 높이 약 0.9 월드 단위에 대해 절반가량으로 잡았습니다.
- 중앙 피벗이 충돌 위치 기준입니다. 캐릭터 좌표 기준인 Deploy와 같은 프리팹 설정을 공유하지 마세요.

## 3.5초 길이를 정확히 맞추기

보스 연출은 84프레임 × 1/24초입니다. Animation 창 Samples=24, Animator 상태 Speed=1을 기준으로 합니다. Animator 전체 Speed를 3.5로 설정하는 뜻이 아닙니다.

1. 001번을 0초, 002번을 1/24초, ... 084번을 83/24초(약 3.458333초)에 배치합니다.
2. **3.5초 위치에 084번 Sprite를 한 번 더 키로 기록**해 마지막 이미지의 표시 시간까지 확보하세요. 새 PNG를 추가하는 것이 아니라 끝 키를 반복하는 것입니다.
3. Loop Time을 끕니다. 사망은 마지막 투명 프레임, 크루저 전환은 마지막 원본 Idle을 유지합니다.
4. 사망 완료 이벤트 NotifyDeathAnimationCompleted를 **3.5초 끝 지점**으로 옮깁니다. 기존 짧은 클립 위치에 남아 있으면 중간에 드롭·제거 흐름이 실행될 수 있습니다.
5. 현재 SpriteResolver 기반 클립을 계속 쓸 경우, Die 카테고리에 84개 라벨을 연결하고 해당 라벨을 애니메이션으로 기록합니다. 새 SpriteRenderer.sprite 트랙과 기존 Resolver 키가 동시에 같은 그림을 덮어쓰지 않게 구성하세요. 기존 공유 Die 클립의 라벨 수만 늘리고 다른 보스 라이브러리를 그대로 두면 다른 보스의 연결도 점검해야 합니다.

Frame_Timing.csv에 모든 프레임의 시작·끝 시간과 3.5초 끝 키가 있습니다. 미리보기 GIF도 총 재생 시간을 3.5초로 맞췄지만 GIF는 시간 단위가 10ms이므로 Unity 24 FPS와 개별 프레임 시간은 약간 다를 수 있습니다.

## 보스별 연출

### Dog 사망

0~0.7초 눈의 과열과 진동 → 0.7~1.3초 턱이 풀리고 추진기 폭발 → 1.3~2.3초 중심 폭발과 원본 장갑·턱 분리 → 2.3~3.5초 파편 낙하, 연기와 잔광 소멸.

### Head 사망

0~1.2초 뇌 덮개 회로 과부하와 청록 전류 → 1.2~1.8초 뇌 부분 에너지 파열과 내부 폭발 → 1.8~2.7초 뇌 덮개·얼굴·턱 장갑 분리 → 2.7~3.5초 잔해·연기 소멸.

### 크루저 사망

0~0.5초 선체 이상 진동 → 0.5~1.6초 후방·중앙·전방 순차 폭발 → 1.6~2.4초 대폭발과 선체 장갑 분리 → 2.4~3.5초 잔해 표류·소멸. 2페이즈 본체 기준이며, 이미 파괴된 타워를 다시 그려 넣지 않았습니다.

### 크루저 1→2페이즈

0~0.8초 파괴된 타워 접합부 방전·방어막 붕괴 → 0.8~1.5초 상부 방열 장갑 열림 → 1.5~2.1초 전방 코어 충전 → 2.1~2.8초 충격파 방출 → 2.8~3.5초 장갑 안정화와 원본 Idle 복귀.

현재 EnterEntityPhase()는 즉시 2페이즈로 바꾸고 본체 Collider를 켭니다. **이 PNG를 넣는 것만으로 3.5초 전환 대기가 생기지는 않습니다.** 추후 전환 상태를 두고 연출 중 패턴·이동·피격 처리 정책을 적용한 뒤 완료 시 2페이즈를 시작해야 합니다. 전환 중 기존 ShieldVisual이 겹치지 않도록, 이 묶음의 방어막 붕괴 그림을 사용할 때 기존 방어막 표시는 별도로 제어해야 합니다.

타워 접합부의 방전 위치는 현재 프리팹의 TowerARoot/BRoot/CRoot 위치와 본체 Renderer 스케일을 기준으로 잡았습니다. 프리팹의 타워 배치를 바꾸면 이펙트 위치도 다시 조정해야 합니다.

## Dog 돌진

Charge 프레임 01~16을 반복 재생하세요. 머리의 크기와 피벗은 고정되고 하악 관절이 열렸다 닫힙니다. 이동은 기존 돌진 코드가 담당하며, 그림에 이동 거리를 포함하지 않았습니다. 현재 Idle 전체를 교체하면 대기 중에도 입을 움직이므로 돌진 전용 애니메이션 상태에 연결하세요. 원본처럼 왼쪽을 바라보는 기준으로 제작했습니다.

## 검증 범위

Validation_Report.json에 RGBA, 투명 여백, 파일 개수, 캔버스, 첫 프레임의 원본 픽셀 일치와 전환 마지막의 원본 복귀 검사 결과를 기록했습니다. 이 검사는 파일 수준입니다. 실제 Unity에서 프레임 연결, 상태 전환, 이벤트, 충돌 판정까지 검증한 것은 아닙니다. 프레임별 수동 확대·축소나 자동 Trim은 정렬을 깨뜨리므로 피하세요.
