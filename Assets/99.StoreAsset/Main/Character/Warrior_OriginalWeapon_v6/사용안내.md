# 워리어 원본 무기 유지 재작업 v6

프로젝트에 자동 적용하지 않은 교체용 파일입니다. 실드, 게임 코드, 클립, 라이브러리, 프리팹은 수정하지 않았습니다.

## 이번 파일

- 자이언트소드: Idle 6장, Move 6장, Attack1 6장. Attack2/Attack3 각 6장은 PrepareOnly에 분리.
- 해머: Idle 6장, Move 6장, Attack1 6장. Attack2/Attack3 각 6장은 PrepareOnly에 분리.
- Slash: Idle 6장, Move 6장, Attack 6장. 이전 장검 그림을 유지하고 본체 정렬을 수정했습니다.
- 검/해머 1격 궤적: 각 6장. 01/02는 준비 동작 중 이펙트가 나오지 않도록 의도적으로 완전 투명합니다.
- 총 본체 78장(지금 교체 54 + 준비만 24), 별도 이펙트 12장.

검/해머는 프로젝트 Parts 폴더의 기존 무기 PNG를 크기 변경 없이 회전·합성했습니다. 원본 검 1202×294, 원본 해머 1277×1130 픽셀입니다. 새로 생성했던 작은 무기 디자인은 최종 무기로 사용하지 않았습니다.

검과 해머의 손가락을 손잡이 앞에 배치했습니다. 해머 Idle은 팔을 내리고 축을 수평에서 10도 올렸습니다. Idle은 한 기준 자세를 사용하며 가슴 안쪽에 최대 1픽셀 변화만 줬습니다. 발·전체 외곽 범위는 6장 모두 고정입니다. Slash Move는 검이 갑자기 앞으로 튀는 기존 5번 포즈 대신 같은 방향으로 쥔 포즈를 재사용했습니다.

## 먼저 Idle만 교체해서 확인하기

1. 플레이 모드를 종료합니다. 기존 Warrior_ReferenceRemake_v3 폴더를 프로젝트 밖에 백업합니다.
2. 압축을 프로젝트 밖에 풉니다.
3. ReplaceNow/Assets/99.StoreAsset/Main/Character/Warrior_ReferenceRemake_v3/Frames/GiantSword/Idle 안의 PNG 6장을 확인합니다.
4. Windows 탐색기에서 위 6장만 C:/YSJ/SubPF/Assets/99.StoreAsset/Main/Character/Warrior_ReferenceRemake_v3/Frames/GiantSword/Idle 에 같은 이름으로 덮어씁니다.
5. 기존 .meta 파일은 유지합니다. Unity에서 기존 에셋을 먼저 삭제하지 마세요. 이 묶음에는 .meta가 들어 있지 않습니다.
6. Unity로 돌아와 재임포트가 끝나면 기존 Idle 클립을 재생합니다. 동일 경로·이름의 PNG를 덮어쓰므로 기존 GUID와 라이브러리 연결을 유지할 수 있습니다.
7. 같은 방법으로 Hammer/Idle, Slash/Idle을 적용합니다. 이후 Move와 Attack1(또는 Slash/Attack), Effects를 같은 상대 경로에 교체합니다.

한 번에 전체 교체하려면 ReplaceNow 안의 Assets 폴더를 프로젝트 루트에 병합하면 됩니다. 포함된 PNG만 교체되며 Shield 및 Attack2/Attack3 파일은 이 폴더에 포함되어 있지 않습니다. 준비용 PrepareOnly는 지금 병합하지 마세요.

## 임포트 설정

이 파일들은 기존 설정을 유지해 교체하는 방식으로 준비했습니다. 프로젝트 설정을 직접 변경한 것은 아닙니다. 새 경로에 임포트할 경우 아래 값을 수동 적용해야 합니다.

| 항목 | 값 |
|---|---|
| Texture Type | Sprite (2D and UI) |
| Sprite Mode | Single |
| Pixels Per Unit | 100 |
| Pivot | Custom: X 0.5, Y 0.423828125 |
| Filter Mode | Point (no filter) |
| Compression | None |
| Generate Mip Maps | Off |
| Wrap Mode | Clamp |
| Alpha Is Transparency | On |
| Max Size | 4096 |
| Resize Non Power of 2 | None |

모든 최종 PNG 캔버스는 3072×3072입니다. 기존과 같은 발 기준선(이미지 위에서 Y=2000)과 Pivot을 사용합니다. 무기를 포함한 전체 그림의 가운데로 Pivot을 다시 잡거나 자동으로 빈 공간을 자르지 마세요. Pivot은 발바닥 위치 자체와 같은 뜻이 아닙니다. 기존 프리팹 위치 관계를 유지하는 값입니다.

플랫폼 Override가 켜져 있으면 해당 플랫폼의 Max Size/Compression도 확인합니다. 3072 원본이 2048 이하로 축소되지 않아야 합니다. Transform Scale은 기존 값을 유지합니다.

## 연결 및 보류 범위

- 동일 이름 덮어쓰기에서는 기존 클립/Resolver 라벨을 새로 찍을 필요가 없습니다.
- GiantSword/Hammer 라이브러리: Idle, Move, Attack1의 01~06.
- Slash 라이브러리: Idle, Move, Attack의 01~06.
- PrepareOnly의 2·3격 24장은 아직 라이브러리나 클립에 연결하지 않았습니다.
- 누르고 있을 때 3연격을 실행하는 코드와 공격 히트박스는 수정하지 않았습니다. 새 동작에 맞춘 타이밍·히트박스 검증은 이후 구현 단계에 남아 있습니다.
- 캐릭터 선택 화면을 포함한 실제 Unity 실행 결과는 아직 검증하지 않았습니다.
