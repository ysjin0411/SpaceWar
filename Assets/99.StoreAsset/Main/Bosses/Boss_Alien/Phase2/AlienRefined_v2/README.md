# 에일리언 패턴 보완 에셋 v2

## 교체 범위
- Leap_01_Crouch: 준비 중 실제 웅크림.
- Leap_02_Takeoff: 이륙.
- Leap_03_Airborne: 공중 유지.
- Leap_04_Landing: 착지. 이후 기존 Phase2 Idle로 복귀.
- TraceFX_01_Rise -> TraceFX_02_Peak -> TraceFX_03_Fade: 지면 발톱 시각 효과.
- 기존 Idle, Combo 9장, Trace 본체 3장, 경고 이미지와 도약 충격파는 유지한다.
- 기존 ExactOutline의 발광 전용 Leap과 새 자세 이미지를 동시에 순서대로 섞지 않는다. 새 4장이 동작 표현을 대체한다.

## 공통
모두 1254x1254, 실제 투명 알파 PNG. Single, PPU 100, Full Rect, Point, 압축 없음으로 가져온다. 각 파일은 한 프레임이므로 Slice하지 않는다. 생성된 주요 자세이며 완성된 보간 애니메이션은 아니다. 크기/팔다리 윤곽이 픽셀 단위로 완전히 일치하지 않으므로 Unity 연속 재생에서 최종 확인한다.

## 도약
Pivot Center를 시작점으로 사용한다. 루트의 평면 위치 이동과 Visual의 높이 이동은 코드에서 분리한다. 공중 프레임에는 다리를 접은 만큼 발 위치가 올라가 있으므로 루트 콜라이더 위치를 스프라이트 발끝으로 매번 이동시키지 않는다. 준비/착지의 지면 정렬은 시각 자식의 위치를 조절한다. 착지 충격파와 경고는 별개 오브젝트로 둔다.

## 발톱 효과 기준점
생성만으로 뿌리 픽셀이 완전히 고정되지는 않았다. Trace_Pivots.csv는 각 파일 중앙 뿌리의 맨 아래 불투명 끝(알파>128)을 측정한 Custom Pivot이다. Sprite Editor에서 해당 파일별 Pivot X/Y를 입력하면 중앙 뿌리 끝을 같은 월드 위치에 놓을 수 있다. CSV Y는 Unity 기준 아래에서 위로 정규화한 값이다.
이 값은 중앙 뿌리 끝을 맞추는 기준이며 세 뿌리의 모양 전체가 같다는 뜻은 아니다. 경고 중심과 실제 분출 중심을 맞출 때 세 프레임 공통 Visual 오프셋을 추가로 조절한다. 피해 판정의 radius는 이미지 높이와 분리한다. Unity에서 실제 미리보기 검증은 아직 하지 않았다.

## 보존
프로젝트 파일과 기존 이미지는 수정하지 않았다. 내장 image_gen으로 제작했으며 prompts.txt에 생성 프롬프트를 기록했다.
