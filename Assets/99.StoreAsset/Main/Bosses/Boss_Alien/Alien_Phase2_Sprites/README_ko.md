# 에일리언 2페이즈 스프라이트
기존 프로젝트를 수정하지 않고 별도로 생성한 개별 PNG 19장입니다.
생성 도구: 내장 image_gen. 원본을 다시 샘플링하거나 배경을 임의 제거하지 않았습니다.

## 기준과 검수
- 참조: 프로젝트 AlienIdleLeap 폴더의 Idle 및 Leap.
- 기존 8장과 신규 19장 모두 캔버스 1254 × 1254.
- 기존 Unity 설정: Sprite Mode Single, Pixels Per Unit 100, Pivot Center (0.5, 0.5).
- 자주색 생체 갑각, 뒤로 뻗은 머리, 보라색 눈과 흉부 발광, 왼쪽 아래를 향한 3/4 시점을 참조했습니다.
- 신규 PNG 19장 모두 전체 픽셀의 알파를 검사했습니다. 결과는 alpha_validation.csv에 있습니다.
- 각 PNG는 자세 하나 또는 하나의 공격 지점에 쓰는 이펙트 하나입니다. 스프라이트 시트 슬라이싱이 필요 없습니다.
- 지면 발톱의 세 갈래는 하나의 공격 이펙트이며, 서로 다른 애니메이션 프레임을 합친 이미지가 아닙니다.
- 생성형 이미지이므로 관절, 발 위치, 세부 윤곽이 모든 프레임에서 픽셀 단위로 고정된 것은 아닙니다. Unity 애니메이션 연결 검증은 수행하지 않았습니다.

피해 판정은 정한 공격 구간에서만 켜야 하며, 이미지의 손끝 위치 자체가 판정 범위를 보장하지 않습니다.

발톱 이펙트는 전체 이미지 중앙이 아닌 중앙 발톱의 땅 접촉점을 기준으로 정렬하세요.
Rise는 Peak보다 접촉점이 아래에 있으므로 같은 중앙 피벗을 그대로 쓰면 상하로 흔들릴 수 있습니다.
Sprite Editor에서 각 프레임의 중앙 균열 접촉점을 피벗으로 지정하면 기록 지점과 일치시킬 수 있습니다.
보스 본체와 지면 이펙트는 서로 다른 Renderer로 사용하는 것을 전제로 합니다.
3번을 BossPattern 상속 체력 특수 패턴으로 사용하고, 2페이즈 체력 구간 안에서 발동 수치를 조절한다는 요구는 후속 구현 조건입니다. 이번 결과에는 코드나 설정 변경이 없습니다.

기존 Crouch → Takeoff → Airborne → Landing에 Recover를 연결하는 구성입니다.

경고와 충격파는 정면에서 내려다본 원형 이펙트이며, 실제 판정 반경에 맞게 크기를 지정해야 합니다.
충격파는 단일 프레임으로, 확장 및 알파 감소를 통해 재생할 수 있습니다.

## 가져오기와 확인
본체 스프라이트는 기존과 동일한 PPU 100을 시작점으로 사용하세요.
보스 프리팹 전체 크기를 새 그림에 맞춰 바꾸기보다, 기존 Idle과 번갈아 보면서 본체 피벗과 접지 위치를 확인하세요.
팔을 올리거나 몸을 숙이는 동작은 전체 불투명 영역의 높이가 달라지는 것이 정상입니다. 프레임마다 그림 전체 높이를 강제로 같게 맞추면 신체 크기가 변합니다.
이펙트는 본체와 별도로 실제 공격 범위에 맞추세요.
이번 묶음은 패턴의 주요 자세 및 이펙트 프레임입니다. 고프레임 보행/공격 중간동작 전체를 포함하는 애니메이션 팩은 아닙니다.
