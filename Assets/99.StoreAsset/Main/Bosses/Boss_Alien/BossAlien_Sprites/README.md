# Boss Alien sprites
새로 생성한 개별 PNG 16개입니다. 프로젝트 코드, 프리팹, 원본 에셋은 수정하지 않았습니다.
이미지 생성: 내장 image_gen. 최종 프롬프트는 generation_prompts.json에 있습니다.

## 구성
- Idle_Modular_01~04: 그랩용 팔 없는 본체, 표시등의 밝기가 변하는 대기 루프.
- Hatch_Open_01~04: 같은 본체의 흉부 미사일 발사구 개방. 마지막 프레임 유지 후 발사.
- Missile_Body: 왼쪽 방향의 미사일. 곡선 궤적은 코드로 이동/회전시킵니다.
- Missile_Exhaust_01~02: 미사일 뒤에 붙일 추진 불꽃 루프.
- Missile_LaunchFlash: 발사 순간 소켓에 표시할 빛.
- Missile_Explosion_01~04: 충돌 시 재생할 폭발, 확산, 소멸.
- Reference/Original_Body_Modular.png: 크기 비교용 기존 원본의 복사본입니다.

## 가장 중요한 크기 기준
본체 8컷의 캔버스는 원본과 동일한 1254x1254입니다. 빈 여백을 잘라내지 않았습니다.
기존 본체의 오른쪽 배치와 중앙 Pivot을 유지합니다.
원본의 실제 외곽(alpha >= 16): (513,154)-(1196,1148), 높이 994px.
새 본체 높이 993~996px. 외곽 좌표 차이는 최대 3px입니다.
생성 이미지이므로 외형 내부까지 완전히 동일한 픽셀은 아닙니다. Unity에서 교체 재생하며 최종 연결 상태를 확인하세요.
measurements.json에 개별 측정 결과가 있습니다. 아주 희미한 알파 잔여 픽셀을 제외하기 위해 외곽은 alpha >= 16으로 측정했습니다.
모든 파일에 실제 알파 채널과 완전 투명 픽셀이 존재합니다. 검은색 배경을 구워 넣은 이미지가 아닙니다.

## Unity Import 기준 (Transform Scale 1,1,1)
| 파일 | PPU | Pivot |
|---|---:|---|
| Idle / Hatch 본체 전체 | 100 | Center (0.5,0.5) |
| Missile_Body | 720 | Center (0.5,0.5) |
| Missile_Exhaust 2컷 | 1000 | Custom (0.25,0.5) |
| Missile_LaunchFlash | 600 | Custom (0.57,0.5) |
| Missile_Explosion 4컷 | 600 | Center (0.5,0.5) |

본체 이외 이미지는 생성 해상도가 다르므로 위 PPU를 적용해야 크기 비율이 맞습니다.
미사일 실제 길이 약 1.40유닛, 전체 날개 높이 약 0.50유닛.
본체 실제 높이는 약 9.94유닛입니다. 추진 불꽃은 길이 약 0.88~0.99유닛.
폭발 최대 지름은 약 1.94유닛입니다. 최종 게임 밸런스에 따른 크기 조절은 별도입니다.
개별 파일별 정확한 값은 Unity_Import_Settings.csv에 있습니다.
Sprite Mode: Single / Filter Mode: Point / Compression: None / Max Size: 2048 / Generate Mip Maps: Off.
원본을 자르거나 Sprite Editor에서 각 프레임을 다르게 Trim하지 마세요.

## 연결 기준
- 모든 본체 프레임에서 분리형 GrabArm을 함께 사용합니다. 몸통 이미지에 그랩 팔은 없습니다.
- Idle 01→02→03→04 반복. 4fps로 비교하며 밝기 변화를 확인하세요.
- Hatch는 Idle의 닫힌 상태에서 01→02→03→04 개방. 발사 중 04 유지. 닫기는 역순 후 Idle.
- 미사일은 왼쪽(-X)을 향합니다. 이동 방향에 따라 회전시키세요.
- 불꽃은 오른쪽(+X)으로 뻗습니다. 미사일 자식으로 붙이고 같은 회전을 따릅니다.
- 위 Pivot과 PPU 기준으로 불꽃의 초기 로컬 위치는 미사일 중심 기준 대략 (0.66,0,0)입니다. 노즐에 맞춰 미세 조절하세요.
- 완전 개방 흉부의 튜브 중심은 대략 픽셀 (735,410),(782,410),(735,471),(782,471)입니다.
- 본체 중앙 Pivot, PPU100 기준 튜브의 로컬 위치는 대략 (1.08,2.17),(1.55,2.17),(1.08,1.56),(1.55,1.56)입니다.
- 이 좌표는 이미지 기준 초기 배치값이며 최종 GameObject의 부모 Transform과 Scale에 따라 월드 위치가 달라집니다.
- 기존 MissileFirePoint 또는 여러 자식 소켓을 튜브 위치에 맞추면 됩니다. 이 작업에서 프리팹은 수정하지 않았습니다.
- 발사 섬광은 짧게 표시하고, 폭발 4컷은 반복하지 않은 뒤 제거합니다.
