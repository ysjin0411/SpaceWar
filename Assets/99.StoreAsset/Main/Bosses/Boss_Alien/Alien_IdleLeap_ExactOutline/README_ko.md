# 전체 윤곽 동일 버전 — Idle / Leap 발광 프레임 9장

사용자가 선택한 '모든 프레임의 전체 윤곽을 동일하게' 기준으로 제작했습니다.

## 결과
- 1254 × 1254, 개별 투명 PNG 9장.
- 기준: Alien_IdleLeap_v2/Idle/Alien_Idle_01.png.
- 모든 프레임의 모든 알파 값을 기준 이미지에서 그대로 보존했습니다.
- 눈과 흉부의 제한된 발광 영역 안에서 RGB만 변경했습니다.
- 해당 영역 밖의 RGB도 모두 동일합니다.
- 외곽선, 발 위치, 몸 크기, 자세가 모두 동일합니다.

## 표현 범위
전체 윤곽 동일 조건에 따라 모든 이미지가 동일한 Idle 자세입니다.
Leap 폴더의 파일은 준비/이륙/공중/착지/회복 시점에 사용할 발광 변화입니다.
웅크림, 다리 접기, 바닥 짚기 등 서로 다른 도약 자세는 포함하지 않습니다.
앞선 자세별 Leap 세트와 표현 목적이 다릅니다.
Combo/Trace 파일은 이번 편집 대상이 아니며 변경하지 않았습니다.

## 파일 순서
Idle: Alien_Idle_01 → 02 → 03 → 04 → 01 반복.
Leap:
1. Alien_Leap_01_ChargeGlow.png — 발광을 낮춘 준비
2. Alien_Leap_02_LaunchGlow.png — 강한 이륙 발광
3. Alien_Leap_03_AirborneGlow.png — 공중 유지 발광
4. Alien_Leap_04_ImpactGlow.png — 가장 밝은 착지 발광
5. Alien_Leap_05_RecoverGlow.png — 기본 발광으로 회복

모든 프레임은 같은 PPU와 Pivot으로 사용합니다.
기존 기준 설정: PPU 100, Pivot Center (0.5, 0.5).

## 검증
각 출력 PNG를 저장 후 다시 읽어 기준 이미지의 1,572,516픽셀과 비교했습니다.
9장 모두 알파 불일치 0픽셀, 발광 영역 밖 RGB 불일치 0픽셀입니다.
알파 SHA-256도 9장 전부 동일합니다:
49CF30F612717314CA5390B9498DC8CD854B509F939867A1E9A5BBD7309A6624
상세 결과는 pixel_verification.csv에 있습니다.
전체 알파가 같으므로 임의의 동일 알파 임계값으로 계산해도 실루엣은 같습니다.
발광 영역 내부의 RGB 변화가 있으므로 전체 RGBA 파일이 서로 동일한 것은 아닙니다.
