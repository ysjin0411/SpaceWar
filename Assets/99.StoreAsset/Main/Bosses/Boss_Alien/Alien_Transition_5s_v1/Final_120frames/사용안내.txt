에일리언 5초 페이즈 전환 — 최종 120프레임

프로젝트 파일은 수정하지 않았습니다. 이 폴더의 Frames만 최종 스프라이트입니다.
상위 폴더의 Frames는 초기 생성 시험본이므로 사용하지 마세요.

구성
- Frames/Alien_Transition_001.png ~ Alien_Transition_120.png
- 모든 PNG: 1254×1254, RGBA 투명 배경, 동일한 캔버스와 중심 피벗
- 24fps, 재생 길이 5초, 반복 없음
- Preview_5seconds.gif: 순서와 동작을 확인하는 배경 포함 미리보기

- timeline.csv: 모든 프레임의 재생 시간과 단계
- validation.json: 크기·마지막 프레임 비교 검사 결과

연출 순서
0.00~0.50: 균열과 전기 스파크, 로봇 파손
0.50~1.20: 가슴 해치 개방, 내부의 작은 에일리언 노출
1.20~1.75: 작은 에일리언 한 마리 낙하, 중력 가속
1.75~2.00: 로봇 발과 같은 높이로 착지, 착지 자세 회복
2.00~2.50: 작은 에일리언이 고개를 들며 외침, 몸에서 빛 발생
2.50~3.70: 발을 지면에 유지한 채 서서히 성장
3.70~4.00: 성체의 빛이 가라앉으며 외형 노출
4.00~4.60: 성체 하울링; 화면 흔들림을 넣을 구간
4.60~5.00: 원본 Idle 자세로 복귀, 2페이즈 연결
파손 로봇은 착지 이후 부품으로 무너지고 성장 초반에 소멸합니다.
화면 흔들림, 사운드, 공격 판정은 PNG에 포함하지 않았습니다.

- Alpha Is Transparency: 활성화
- 플랫폼별 오버라이드가 이미지를 축소하지 않는지 확인
- 자동 Trim, 개별 여백 자르기, 프레임별 Pivot 변경 금지

클립 재생
번호 순서대로 1/24초 간격으로 배치합니다.
001 = 0초, 002 = 0.0416667초, 120 = 4.9583333초입니다.
클립의 끝을 정확히 5초로 만들려면 5.000초에도 120번과 같은 값을 넣습니다.
Animation Samples = 24, Animator State Speed = 1, Loop Time = 꺼짐.
Speed를 5로 설정하는 것이 아니라 클립 길이를 5초로 설정합니다.
현재 클립은 SpriteResolver.m_SpriteHash 트랙을 사용하므로 기존 방식대로
Sprite Library의 PhaseTransition 카테고리에 순서대로 연결하고 키를 교체합니다.
SpriteRenderer와 SpriteResolver에 서로 다른 스프라이트 변경 트랙을 중복 생성하지 마세요.
권장 Label: Transition_001 ~ Transition_120.
화면 흔들림 시작 후보: 4.20초. 종료 후보: 4.60초.

매우 중요한 스케일·발 높이 기준
이 시퀀스는 로봇의 전환 Renderer가 월드 스케일 1이고 PPU 100인 경우에 맞췄습니다.
에일리언 성장 완료 크기는 원본 Idle 스프라이트를 0.43배 한 크기입니다.
생성되는 Boss_AlienBody의 Scale은 사용자 지정대로 (0.43, 0.43, 0.43)을 사용합니다.
이 시퀀스를 재생하는 로봇까지 다시 0.43배 줄이면 크기가 이중으로 줄어듭니다.

원본 로봇 발 기준 행: 1150
원본 에일리언 발 기준 행: 1188
공통 캔버스 중심: (627, 627)
전환 끝에서 발이 튀지 않으려면 현재 로봇 원점을 기준으로
PhaseTwoSpawnPoint의 Y를 -2.8177, X를 0으로 맞추는 기준입니다.
로봇 BodyVisual, 부모 Transform에 추가 위치/스케일/회전이 없다는 조건입니다.
다른 부모 스케일이나 회전이 있다면 이 수치를 그대로 적용하지 말고 월드 좌표로 환산하세요.
정확한 계산: -(1150 - 627 - 0.43 × (1188 - 627)) / 100 = -2.8177
프로젝트의 스폰 위치는 자동 수정하지 않았습니다.
확인 당시 저장된 Boss_AlienBody 프리팹 Scale은 0이었으므로,
실제 적용 시 사용자가 정한 0.43이 저장되어 있는지도 확인하세요.

1920×1080 화면에서의 크기
화면 해상도만으로 스프라이트의 화면 픽셀 크기가 정해지지는 않습니다.
원본 에일리언 몸체 높이 약 1076px × 0.43 / PPU 100 = 약 4.63 월드 유닛입니다.
직교 카메라 Size가 5이면 화면 높이는 약 500px, Size가 10이면 약 250px입니다.
카메라 줌에 관계없이 0.43배 Boss_AlienBody와 전환 마지막 몸체의 월드 크기는 대응합니다.

외형 보존 및 검증 범위
로봇, 에일리언의 기본 외형·머리·몸체·발은 프로젝트 원본 픽셀을 바탕으로 구성했습니다.
하울링은 원본 머리와 턱을 움직이고, 새로 드러나는 목 부위에 생성한 보조 이미지를 사용했습니다.
낙하·성장·부품 이동은 수치 보간으로 연결했습니다.
움직이는 부품의 회전·축소 과정에서는 보간으로 픽셀 값이 달라집니다.
모든 동작 프레임의 전체 픽셀이 Idle과 동일하다는 의미는 아닙니다.
마지막 120번은 원본 Idle을 지정한 위치에 0.43배 변환한 결과와 RGBA 배열이 일치합니다.
Unity 안에서 임포트·재생 테스트는 수행하지 않았습니다.

제작 방식
내장 이미지 생성 도구로 표현 참고 및 목 보조 이미지를 생성했습니다.
사용자의 명시적 동의 후 Python/Pillow로 원본 부품 합성, 회전, 성장·낙하 보간,
공통 캔버스 배치와 검증을 수행했습니다. 프로젝트 밖에서만 작업했습니다.
