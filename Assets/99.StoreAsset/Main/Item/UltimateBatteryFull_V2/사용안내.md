# Ultimate Battery Full V2

프로젝트를 변경하지 않고 만든 이미지 에셋입니다. 생성 도구: 내장 image_gen.

## 구성
- UltimateBattery_Full_Horizontal.png: 가로로 누운 풀충전 건전지. 드랍 본체와 UI 수량 표시에서 공용으로 사용합니다.
- UltimateBattery_Sparks_2x2.png: 건전지 주변에 겹쳐 재생할 스파크 4프레임. 본체는 포함하지 않습니다.
- UltimateReady_01.png ~ UltimateReady_04.png: 화면 테두리 애니메이션 개별 4프레임. 기존 테두리 대신 이 이미지들을 재생합니다.

## 가져오기
공통: Sprite (2D and UI), Alpha Is Transparency On, Compression None, Mip Maps Off, Pivot Center, Max Size 2048.
건전지: Single, Point. 월드에서 PPU 1550, Scale 1이면 그림 너비 약 0.6유닛입니다.
스파크: Multiple, Point. Grid By Cell Count 2열 2행으로 잘라주세요. 각 셀 627x627.
건전지 본체의 캔버스는 1254x1254이고 스파크 한 셀은 627x627입니다.
따라서 스파크 PPU를 건전지 PPU의 절반(775)으로 두고 양쪽 Transform Scale은 1로 두면 캔버스 크기가 일치합니다.
스파크 자식의 Local Position은 (0,0,0), 본체보다 Sorting Order 1 높게 설정합니다.
스파크 재생 순서: 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래. Samples 8, Loop Time On을 시작값으로 사용합니다.
이전 충전 애니메이션은 이번 버전에서 사용하지 않습니다.

## UI 수량 표시
건전지 정적 이미지 한 개를 한 칸으로 사용합니다.
1개 획득하면 Image 1개, 2개면 Image 2개를 가로로 나란히 표시합니다.
현재 수량을 건전지 내부 충전량으로 나타내지 않습니다.
UI에서 스파크는 생략 가능합니다. Image Preserve Aspect On, Raycast Target Off.
원본은 스파크와 정렬하기 위해 정사각 투명 캔버스를 사용합니다. UI 아이콘 배치 시 투명 여백을 고려하세요.

## 화면 테두리
각 파일 Single, UI Image Type Simple, Raycast Target Off.
동일한 전체 화면 Stretch RectTransform에서 Source Image만 순서대로 교체합니다.
01 → 02 → 03 → 04 → 01, Samples 8, Loop Time On을 시작값으로 사용합니다.
Set Native Size를 프레임마다 호출하지 마세요.
01/02/04는 1670x942, 03은 1669x942로 생성되었습니다. 동일한 UI RectTransform으로 표시 크기를 고정합니다.
테두리 중심은 실제 투명 배경입니다.
이미지 생성 특성상 프레임별 금속 윤곽에 소폭 차이가 있습니다. 픽셀 단위로 고정된 테두리가 필요한 경우 고정 프레임과 전기 효과를 별도 레이어로 제작하는 추가 보정이 필요합니다.

## 생성 프롬프트 요약
1. 기존 네이비 금속/은색 캡/주황 포인트 스타일, 오른쪽 양극 단자, 가로형 풀충전 청록 건전지 한 개, 투명 배경, 외부 스파크 없음.
2. 가로형 건전지 주변에 겹칠 청록/파랑 스파크만 있는 2x2 애니메이션, 중앙 공간 비우기, 투명 배경.
3. 기존 파란 프레임을 기준으로 좌상단→우상단→우하단→좌하단에 강한 전기 펄스를 배치한 개별 4프레임, 중앙 투명.
