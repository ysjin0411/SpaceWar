# 가로 건전지 양 전극 스파크 Idle

본체와 양 전극의 스파크가 합쳐진 4프레임입니다. SpriteRenderer 하나에서 재생합니다.
풀충전 상태는 유지하고 전극의 스파크만 변화하는 컨셉입니다.
내장 image_gen으로 제작했으며 프로젝트 파일은 변경하지 않았습니다.

## 프레임 자르기
Sprite Mode: Multiple, Pivot: Center, Filter Mode: Point, Compression: None.
원본 1254x1254. 자동 슬라이스는 스파크 조각을 나눌 수 있으므로 사용하지 않습니다.
생성된 시트의 위/아래 행 간격이 정확한 등분은 아니므로, Grid By Cell Count 대신 Sprite Editor에서 아래 사각형 4개를 지정하세요.
Unity Sprite Editor의 좌하단 원점 기준 좌표입니다.

| 이름 | X | Y | Width | Height |
|---|---:|---:|---:|---:|
| UltimateBattery_Idle_01 | 0 | 650 | 627 | 500 |
| UltimateBattery_Idle_02 | 627 | 650 | 627 | 500 |
| UltimateBattery_Idle_03 | 0 | 60 | 627 | 500 |
| UltimateBattery_Idle_04 | 627 | 60 | 627 | 500 |

이 사각형들은 각 건전지의 에너지 창 중심을 기준으로 정렬하며, 양 끝 스파크도 포함합니다.
PPU 700, Transform Scale 1이면 건전지 본체 너비는 약 0.6 유닛입니다.
01 → 02 → 03 → 04 순서, Samples 8, Loop Time On을 시작값으로 사용하세요.
본체와 스파크를 별도 자식으로 구성할 필요가 없습니다.
UI에 획득 수량을 표시할 때는 이전의 스파크 없는 풀충전 가로 건전지 이미지를 반복 배치할 수 있습니다.

## 생성 요청
가로로 누운 풀충전 건전지의 4프레임 Idle. 모든 프레임에 건전지 본체와 좌우 전극에서 뻗는 청록색 스파크를 함께 포함. 본체의 충전 상태와 방향을 유지하고 스파크 형태만 변화. 기존 네이비/은색/주황 픽셀 아트, 실제 투명 배경.
