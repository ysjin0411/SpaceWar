# SpaceTown 3 × 2.5 화면 맵

## 사용 방법
1. Unity에서 Assets → Import Package → Custom Package로 SpaceTown_3x2p5.unitypackage를 가져옵니다.
2. Assets/SpaceTown_3x2p5/SpaceTown_3x2p5_Visual.prefab을 Town 씬에 놓습니다.
3. 프리팹 루트의 Position은 (0,0,0), Scale은 (1,1,1)로 둡니다.
4. 카메라는 Orthographic, Size 5, 게임 화면은 1920×1080 (16:9)로 둡니다.
5. 전체 배치는 Scene 창에서 프리팹을 선택하고 F로 확인합니다. 게임 카메라에는 일부만 보이는 것이 정상입니다.

## 크기와 화질
- 전체 시각 영역: 가로 약 53.3333유닛, 세로 25유닛.
- 1920×1080 / Size 5에서 3 × 2.5화면, 화면 픽셀 배치 기준 5760×2700.
- 저해상도 한 장을 확대한 방식이 아닙니다. 고해상도 그림을 스프라이트 16개로 배치합니다. 마지막 벽 구역은 기존 벽 조각을 좌우 반전해 재사용합니다.
- 원본 PNG의 픽셀은 수정하거나 늘리지 않았습니다. 표시 영역과 바닥 높이는 스프라이트 가져오기 설정 및 Transform으로 맞췄습니다. 층간 이음새에는 같은 원본에서 지정한 바닥 보 스프라이트를 재사용합니다.
- 각 원본의 해상도와 실제 표시 크기 검사는 ResolutionChecks.json에 있습니다.
- URP 기본 Sprite-Unlit-Default 머티리얼을 사용해 별도 2D 조명 없이 원본 색상을 표시합니다.
- 게임 창을 16:9가 아닌 비율로 바꾸거나 카메라 Size를 변경하면 화면 개수도 달라집니다.

## 구성
- 포탈 자리: 상층 좌우 총 2곳. 문틀 그림만 있고 실제 포탈 기능/효과는 없습니다.
- 통로 높이 4단, 층을 잇는 계단 3개. 맵 전체 높이는 2.5화면입니다.
- 바탕 우주/관측창/기지 벽 포함. 투명 배경이나 체크무늬는 없습니다.
- PlayerSpawn_FootPoint와 NPC/Portal FootPoint는 발이 닿는 위치를 표시한 빈 오브젝트입니다.
- NPC 캐릭터, 이동 스크립트, 카메라 추적, 포탈 동작, 충돌체는 포함하지 않습니다. 시각 맵 프리팹입니다.
- 콜라이더를 이미지의 모든 기둥과 벽에 자동 생성하면 통로를 막습니다. 실제 발판과 계단 경사면에 따로 배치해야 합니다.

## 카메라 추적 범위 참고
루트가 (0,0,0), Size 5, 화면이 16:9일 때 카메라 중심 범위:
- X: -17.7778 ~ 17.7778
- Y: -7.5 ~ 7.5
이는 배경 밖을 보이지 않게 하는 범위이며, 실제 추적 스크립트는 이후 연결합니다.

## 확인 범위
원본 해상도/파일 무결성, 배치 영역, 스프라이트 참조와 패키지 구조를 검사하고 브라우저로 동일한 배치를 렌더링했습니다.
사용자의 Unity 프로젝트는 수정하지 않았으며 Unity 에디터 안에서의 패키지 가져오기/플레이 실행은 하지 않았습니다.
이미지는 내장 image_gen 도구로 생성했습니다. 전체 생성 프롬프트는 GenerationPrompts.txt에 있습니다.
