게임 전체 SF 사운드 팩 — 사용 안내

현재 프로젝트를 읽고 제작한 직접 합성 PCM WAV 파일입니다. 사람/동물 녹음이나 생성형 음악 서비스의 출력은 사용하지 않았습니다.
프로젝트 파일은 수정하지 않았고 Unity에 자동으로 연결하지 않았습니다.
실제 청음과 게임 내 믹싱은 수행하지 않았습니다. WAV 헤더·샘플 값·클리핑·루프 경계를 수치로 검사했습니다.

1. 파일 구성
01_BGM: 11개 반복 음악. Town 포함, 보스별 테마 포함.
02_Ambience: Town의 작은 환기 배경음.
03_Town_UI: Town 상호작용·창·이동·장비·퀘스트 소리.
04_Menu_UI: MainMenu 로그인·입력음, 캐릭터/스테이지 선택, 업적, 일시정지.
05_Weapons: 병사 5종, 전사 4종, 무기 교체.
06_Combat: 피격·처치·아이템·레벨업·보물상자·궁극기·결과.
07_Bosses: Dog, Head, Cruiser, Alien 전용 패턴.
00_Previews: 청취용 모음. 실제 게임에서는 사용하지 마세요.

2. 씬별 음악
1.MainMenu: mainmenu_signal_loop. 기존 BGM을 유지해도 됩니다. 동시에 두 곡을 재생하지 마세요.
Town: town_bgm_orbital_rest_loop + 필요하면 town_ambience_ventilation_loop를 작게.
EquipmentManage / CharacterSelect: preparation_terminal_loop (독립 씬일 때).
StageSelect: stage_select_navigation_loop (독립 씬일 때).
TownNpcServicePresenter는 서비스를 Additive로 불러오므로 Town 위에서 열 때는 Town BGM 하나를 유지하는 편이 자연스럽습니다.
Stage1: stage1_frontier_loop → boss_dog_pursuit_loop → 일반 전투 → boss_head_distortion_loop.
Stage2: stage2_biomechanical_loop → boss_cruiser_siege_loop → 일반 전투 → boss_alien_phase1_loop → 하울링 → boss_alien_phase2_loop.
Stage3Data는 존재하지만 Stage3 씬은 현재 파일 목록에 없어서 별도의 Stage3 음악은 제작하지 않았습니다.

3. 에일리언 2페이즈 하울링
근거: Alien_PhaseTransition.anim, m_StopTime=5, m_SampleRate=24.
HowlFX는 0초에 Clear 스프라이트, 4.2083335초부터 Alien_HowlFX_001. Animator 상태 기본 speed=1.
선택 A: alien_transition_full_5s.wav를 전환 시작에 1회 재생. 4.208333초에서 강한 하울링이 시작되고 5초에 종료.
선택 B: alien_howl_sync_0p792s.wav를 4.208333초의 하울링 이펙트 시작에 1회 재생.
선택 C: alien_howl_extended_2p4s.wav는 더 긴 하울링+잔향 대안. 이펙트 시작에 재생하면 전환 이후에도 남으므로 보스 교체에 파괴되지 않는 재생기에서 재생.
A/B/C는 대안입니다. 동시에 겹쳐 재생하지 마세요. 전환 속도 또는 Time.timeScale을 변경하면 타이밍을 다시 맞춰야 합니다.
전환 도중 중단될 때 긴 소리가 남지 않도록 별도 AudioSource로 정지 가능하게 관리하세요.

4. 재생 방식
BGM은 Mixer의 BGM 그룹, 효과음은 SFX 그룹으로 보냅니다. 환경음도 현재 두 그룹 구조에서는 SFX.
파일명 *_loop.wav는 유지 재생용입니다. 상황 종료 시 Stop하거나 페이드아웃하세요.
레이저: laser_start → laser_sustain_loop → 최대 출력 때 laser_max_charge_loop로 교체 → laser_stop.
레이저 루프 두 개를 동시에 켜지 마세요. 지속음은 PlayOneShot 반복 호출이 아니라 전용 AudioSource의 Loop로 관리하세요.
기타 짧은 효과음: Loop Off / Play On Awake Off / PlayOneShot으로 해당 이벤트에 1회.
실제로 피해가 들어간 시점에 hit, 실제 발사에 fire. 버튼 눌림만으로 성공/보상음을 내지 마세요.
근접 무기의 swing은 공격 타이밍, hit는 명중에 맞춥니다. 여러 적을 동시에 때릴 때 재생 개수를 제한하세요.
발소리는 지상 이동 중에만 3종을 번갈아 재생. 점프 중/대화 중에는 중지.
병사 궁극기는 코드 기본값상 30발이므로 폭발 소리 30개를 그대로 겹치지 말고 가까운 타격을 묶거나 동시 재생 수를 제한하세요.
경험치·골드·총알 명중은 빈도가 높으므로 작은 볼륨과 재생 간격 제한을 적용하세요.
충전/예고 파일 중 안내에 시간 기준이라고 적힌 것은 현재 패턴 지속시간에 맞춰 시작·종료 또는 별도 루프화를 조정해야 합니다.

5. 시작 볼륨 예시 (게임 청음 후 조절)
BGM AudioSource 0.30~0.45, UI 0.45~0.70, 일반 무기 0.40~0.65, 보스 하울링 0.65~0.85, Town 환경음 0.15~0.30.
파일 피크에 여유를 두었지만 여러 소리가 겹치면 총 출력은 커집니다. 최종 밸런스는 실제 게임에서 확인하세요.

6. 형식 및 가져오기
새 파일: 44.1kHz / 16bit PCM, BGM·환경음 스테레오, 효과음 모노.
기존 MainMenu에서 가져온 3개는 48kHz / 16bit PCM 모노이며 정상입니다.
압축을 푼 뒤 원하는 WAV 파일만 Unity Project 창으로 가져오세요. .wav 확장자를 유지하세요.
00_Previews, generate_audio.cjs, JSON, 안내문은 Assets에 넣을 필요 없습니다.
클립 자체에 루프 플래그가 기록되는 것은 아닙니다. Unity AudioSource의 Loop를 설정해야 합니다.
